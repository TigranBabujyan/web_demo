# Web Demo / Paranoid Visuals Prototype

**Experimental frontend and visual-prototype repository for UI exploration, Figma/MCP workflows, and interactive visual direction.**

This repository is a development snapshot of an experimental visual application. It is kept public to show exploration around modern frontend workflows, design-to-code tooling, and prototype-driven development.

---

## Project Status

This is not a finished production application. The active version of the project is being developed separately, while this repository remains as a public prototype/demo version.

The goal of this repo is to document the experiment and make the repository understandable for reviewers instead of leaving it as raw code with no context.

---

## What It Demonstrates

- Prototype-first frontend workflow
- Visual / interaction exploration
- Figma integration experiments
- MCP-related development setup
- Node.js scripting around design tooling
- Early-stage product and UI iteration

---

## Tech Stack

| Area | Technology |
|---|---|
| Runtime | Node.js |
| Tooling | Model Context Protocol SDK |
| HTTP client | Axios |
| Design workflow | Figma-oriented integration experiments |

## Getting Started

```bash
git clone https://github.com/TigranBabujyan/web_demo.git

npm start
```
